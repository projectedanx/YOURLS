## Modernizer — Modernize legacy variable declarations in JavaScript
**Learning:** Lexically unbounded `var` declarations in JavaScript introduce legacy hoisting risks and loose variable scopes. Utilizing `const` (where variables are not reassigned) and `let` (where reassignment is needed) ensures variables adhere to modern ES6 block-scoped semantics, reducing potential unintended side effects. Previously, we also learned that migrating legacy `isset($var) ? $var : 'default'` patterns to the PHP 7+ Null Coalescing Operator (`$var ?? 'default'`) reduces cognitive overhead and verbosity safely (PHP ^8.1 natively handles it).
**Action:** Replaced `var` with strictly scoped `const` and `let` keywords inside `js/insert.js` while maintaining correct closure logic and minimizing cross-browser compatibility issues. Previously, we replaced loose logical ternary fallbacks with strict nullish coalescing operators (`??`) across `includes/functions-api.php`, `yourls-api.php`, and `yourls-loader.php` to prevent false-falsy bugs and reduce visual clutter without altering behavior.
